Validate with your own reference gates

Generate a report by replaying a FlowJo workspace against its matching FCS files and comparing the recomputed counts with the counts saved in FlowJo. Private experiments and generated reports are not included in this repository.

Upload FCS files and draw gates

Drop files anywhere on this page or choose them from your computer.

.fcs files · up to 100 MB each · local analysis

To create a local comparison report after installing the validation dependencies:

python scripts/validate_workspace.py --workspace /path/to/reference.wsp --fcs-dir /path/to/fcs_files

The report distinguishes stored reference counts from fresh calculations. Replaying saved gates does not establish automatic gate selection or event-by-event equivalence.
