# Worked analysis examples

These examples accompany the [browser tutorial](../docs/TUTORIAL.md). They use Aureka Flow's analysis engine, which delegates saved gate calculations to FlowKit. No experimental files are included or discovered on your computer.

## 1. Reproduce the synthetic yeast-display walkthrough

From an installed source checkout:

```sh
python examples/analyze_synthetic.py
```

The example generates the same three demo FCS samples in memory, restores the exact tutorial gates, checks every population count against the published reference, and writes:

| File in `exports/synthetic-walkthrough/` | Contents |
| --- | --- |
| `interactive-analysis.html` | An offline Plotly figure: expression/binding scatter and comparative binding distributions. Open it in a browser; Plotly is bundled in the file. |
| `population-counts.csv` | Every population's count, parent, % of parent, % of total and source hash. |
| `analysis-summary.json` | Conditional binding fractions, transformed medians, comparison rows, axis settings and software versions. |
| `gate-project.json` | The gate strategy and synthetic source provenance; load the demo in the app before opening this project. |

Choose another destination with `--output /path/to/output`. Existing example files at that destination are overwritten. The default output folder is excluded from Git. These generated HTML/JSON/CSV files contain synthetic data only; an event CSV is not generated by this example.

The saved HTML supports zoom, hover, legend toggles and visual selections. Selections there do not recalculate gates or statistics; use the app or edit the Python analysis to define a new strategy.

Expected summary:

| Synthetic sample | E+ B+ count | Expression+ count | E+ B+ / Expression+ |
| --- | ---: | ---: | ---: |
| Control | 501 | 24,299 | 2.06% |
| Expression | 7,357 | 24,284 | 30.30% |
| Binding | 15,795 | 24,386 | 64.77% |

These are computed fractions, not measured affinity or biological replicate results. The scatter is sampled to at most 25,000 events; gates and histograms use the full event data. Medians are in saved Logicle coordinates. See [all reference results](../docs/DEMO_RESULTS.md) and the [denominator explanation](../docs/TUTORIAL.md#read-the-results-with-the-right-denominator).

To learn the underlying toolkit directly, use the official [FlowKit tutorial series](https://flowkit.readthedocs.io/en/latest/tutorials.html). Aureka Flow currently pins FlowKit 1.2.3; check the corresponding version's API when adapting upstream examples.

## 2. Replay an existing human FlowJo strategy

The [workspace validation command](../README.md#compare-with-a-human-flowjo-workspace) reads a supplied `.wsp` and matching FCS files. It compares stored human counts with fresh FlowKit calculations and produces a local HTML report, comparison table and source hashes. Inputs and outputs remain excluded from the public repository.

This example requires your own matching inputs, or a separately obtained upstream public data set. It replays existing gates; it does not automatically choose gates or establish event-level agreement from counts alone.
