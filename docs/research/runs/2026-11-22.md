## Reproduced problem and change

The browser validator rejected conflicting `SPILL`/`SPILLOVER` and non-finite matrices, while the native batch adapter independently selected the first keyword. Generated fixtures reproduced silent native acceptance of conflicting keywords and a NaN coefficient. The new regression file initially had nine failures, including missing new provenance fields; malformed/singular rejection already worked.

Native `core analyze` and `run` now call the same validator as the browser when embedded compensation is explicitly requested. Invalid matrices stop before results are written. Source-value modes remain usable without applying the embedded matrix. Equivalent numeric keyword representations remain accepted. Native measurements retain per-keyword hashes, the existing preferred-keyword hash, original event ranges and a separately unverified source-compensation history.
