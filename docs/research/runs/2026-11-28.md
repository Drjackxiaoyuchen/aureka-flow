## Improvement and contracts

The pinned FlowIO 1.3.0 parser removes dollar characters from TEXT values. Distinct synthetic detectors `FITC$-A` and `FITC-A` collide under the old path; escaped separators and UTF-8 labels also differed between inspection and event analysis. Both Aureka import paths now share the existing bounded primary HEADER/TEXT reader, decode UTF-8 with whole-segment Latin-1 fallback, and reject duplicate case-insensitive keywords before workspace mutation. Literal metadata and detector/stain labels are supplied through public FlowData attributes before FlowKit constructs mappings, preprocesses or compensates events.

DATA decoding still uses pinned strict FlowIO checks. An explicit comparison rejects disagreement in DATA-decoding metadata before constructing the sample. Inspection of installed FlowKit 1.2.3 confirms gain, amplification and Time preprocessing read the restored metadata, rather than cached channel attributes. Three additional tests reject malformed literal numeric values that upstream dollar removal would otherwise turn into valid numbers. No guessed channel alias, input rewrite, dependency change or external workspace replay change is introduced. Existing projects based on altered names need explicit gate review.
