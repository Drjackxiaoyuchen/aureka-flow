## Limits and next priority

This is numeric boundary/vertex editing, not graphical gate dragging or reparenting. Sibling gates, including the reconstructed quadrant rectangles, remain independent: editing one can create overlap/gaps, so do not assume an edited set partitions its parent. History is session-local and is deliberately not replayable across source/compensation replacements.

FACSMelody/FACSChorus still needs a permitted authentic FCS export tied to software version, export/compensation settings, associated experiment/sort metadata and an independent reference. The private FACSDiva example still needs matched nonzero vendor statistics and height/width review before any count-equivalence claim. The open public qualification's count disagreement remains unresolved and is not addressed by this UI feature. No live instrument interface was added.

Next independent product priority: dependency-aware Boolean populations, followed by named sample groups and reviewed per-sample overrides. Reusable reporting layouts and graphical gate dragging stay queued. None of these synthetic fluorescence/count checks establishes affinity or cellular function.
